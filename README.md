# hong-yi/tap

Homebrew formulae by [hong-yi](https://github.com/hong-yi).

## Install

```sh
brew install hong-yi/tap/<formula>
```

Or tap it once, then install by name:

```sh
brew tap hong-yi/tap
brew install <formula>
```

## Formulae

| Formula | What it is |
|---|---|
| [`poui`](Formula/poui.rb) | Opens your relevant developer portals ([hong-yi/poui](https://github.com/hong-yi/poui)). |

`poui` used to come from `hong-yi/poui` (the `homebrew-poui` tap). If you installed it from
there, move over with:

```sh
brew uninstall poui
brew untap hong-yi/poui
brew install hong-yi/tap/poui
```
